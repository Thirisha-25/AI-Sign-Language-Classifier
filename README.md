# AI Sign Language Classifier

An AI-powered web application that recognizes sign language letters from A to J using a webcam.

## Features

- Real-time webcam sign language recognition
- Recognizes letters A-J
- AI prediction using Google Teachable Machine
- TensorFlow.js integration
- Confidence percentage
- Confidence progress bar
- Prediction history
- Responsive design for desktop and mobile

## Technologies Used

- HTML
- CSS
- JavaScript
- TensorFlow.js
- Teachable Machine
- Web Camera API

## How It Works

The webcam captures the user's hand gesture and sends the image to the trained Teachable Machine model. The model predicts the corresponding sign language letter and displays the prediction with its confidence percentage.

## Sign Language Classes

The model is trained to recognize:

A, B, C, D, E, F, G, H, I and J.

## How to Use

1. Open the application.
2. Click **Start Camera**.
3. Allow camera permission.
4. Click **Start Prediction**.
5. Show a sign language letter from A-J.
6. View the predicted letter and confidence score.
